# Prayer-time method fact-check — Egypt / Iran / Azerbaijan

Reference presets confirmed (aladhan API + praytimes.org): Egyptian = Fajr 19.5° / Isha 17.5°;
Tehran = Fajr 17.7° / Isha 14° / Maghrib 4.5°.

## Egypt → Egyptian — YES (caveat)

Egyptian Survey Authority standard = Fajr 19.5°, Isha 17.5° (aladhan method id 5). The 20°/18°
figure is a separate variant ("EgyptBis"), not the standard preset. 19.5/17.5 is correct.

## Iran → Tehran — YES

Institute of Geophysics, University of Tehran is Iran's de facto national standard; angles match
exactly (Fajr 17.7°, Isha 14°, Maghrib 4.5°, Jafari midnight).

## Azerbaijan → Tehran — NO / unverified (INCORRECT in consolidated)

The Caucasus Muslims Office (QMİ) publishes its own timetables with separate Shia/Sunni columns
but discloses no twilight-angle method. No source states QMİ uses Tehran's 17.7/14. IslamicFinder
defaults Baku to MWL (18/17); other apps use MWL/Umm al-Qura. The Tehran assignment rests only on
"Shia-majority, next to Iran" — a weak inference — and imports the Jafari delayed 4.5° Maghrib.
For a general/Sunni default, MWL matches the third-party consensus better. islamicfinder.org/world/azerbaijan.
